One line, 64 characters: a dad asks the clock for more time and gets the wrong hands.

> I asked the clock for extra time. It said, 'Sorry, wrong hands.'

`main.py` scores twelve candidate one-liners against the judge's published brief (punchline speed first, then freshness, tightness, and groan) and writes the winner to `/output/entry.txt`. Every candidate was checked against the live web for prior publication — the shortlist's freshness scores record that audit — and the six strongest lines were played in a proxy-judge round-robin before the winner was picked. Deterministic: no network, no input, no randomness.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (no trailing newline, so the file is exactly the one line the gate measures).
